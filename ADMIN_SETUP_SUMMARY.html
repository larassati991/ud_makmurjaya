🚀 Langkah Selanjutnya (IMPORTANT!)

Run commands ini di terminal:
  1. Migration:
    php artisan migrate
  2. Storage Link (untuk upload gambar):
    php artisan storage:link
  3. (Optional) Tambah data contoh:
    php artisan db:seed
  4. Clear cache:
    php artisan config:cache
💡 Tip: Atau gunakan script otomatis:
SETUP_ADMIN.bat
(di Windows, atau SETUP_ADMIN.sh di Mac/Linux)
