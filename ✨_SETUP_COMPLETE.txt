❓ TROUBLESHOOTING

PROBLEM: Gambar tidak bisa diupload
→ Jalankan: php artisan storage:link

PROBLEM: Gambar tidak tampil di website
→ Jalankan: php artisan storage:link

PROBLEM: Error saat tambah produk
→ Jalankan: php artisan migrate

PROBLEM: Produk tidak muncul di website
→ Check: Apakah produk & kategorinya AKTIF?

PROBLEM: Tidak tahu cara mulai
→ Baca: QUICK_START.md atau ADMIN_PANEL_GUIDE.md

📝 TIPS

Untuk Upload Gambar:
  ✓ Gunakan format JPG atau PNG
  ✓ Ukuran minimum: 400x300px
  ✓ Max file size: 2MB
  ✓ Nama file: Deskriptif (auto-slugified)

Untuk Input Data:
  ✓ Nama produk: Jelas & deskriptif
  ✓ Harga: Double-check akurasinya
  ✓ Deskripsi: Tulis detail, manfaat, cara penyajian
  ✓ Jangan lupa: Aktifkan produk agar tampil
